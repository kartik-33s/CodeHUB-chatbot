> **A comprehensive, interactive dashboard to explore India's global rankings across economy, technology, governance, environment, and quality of life.**

🌐 **[Live Demo](https://kartik-33s.github.io/CodeHUB-chatbot/)** | 📹 **[Video Demo](#)** | 📊 **[Data Sources](#data-sources)**

## 🎯 Overview

India is one of the world's largest and fastest-growing economies, but progress cannot be measured by economic growth alone. This dashboard consolidates global rankings from leading international organizations into a single, accessible platform - helping citizens, researchers, journalists, and policymakers understand **where India stands on the global stage**.

### Key Features

✨ **13 Global Indicators** covering:
- 🌍 Economy (GDP, Innovation Index)
- 👥 People (Human Development Index)  
- 🌱 Sustainability (SDG Index, Environmental Performance)
- 💻 Technology (Network Readiness, AI Readiness)
- ⚖️ Governance (Corruption Index, Rule of Law)
- 🗞️ Rights (Press Freedom)
- 🕊️ Quality of Life (Peace Index, Happiness Report)
- ⚖️ Equality (Gender Gap)

## 🚀 Features

### Core Functionality
- ✅ **Interactive Dashboard** - Visual overview of India's global standing
- ✅ **Progress Compass** - Radar chart showing percentile rankings across categories
- ✅ **Country Comparison** - Compare India with peers (US, China, Germany, Brazil, etc.)
- ✅ **Historical Trends** - Visualize ranking changes over time (2020-2026)
- ✅ **Interactive World Map** - Geographic view with country pins
- ✅ **Search & Filter** - Find indicators by name, category, or rank band
- ✅ **Source Attribution** - Every metric links to original data source

### Bonus Features
- 🤖 **AI-Powered Insights** - Generate analysis through different lenses (economy, people, governance, environment)
- 💬 **Natural Language Search** - Ask questions like "Show India's innovation ranking"
- 📄 **Annual Report Card** - Download comprehensive text report
- 📊 **CSV Export** - Export all data for further analysis
- 📚 **Indicator Catalog** - Browse complete list of current & planned indicators
- ✅ **Challenge Readiness** - Track deliverables alignment

### Technical Highlights
- 📱 **Fully Responsive** - Works on desktop, tablet, and mobile
- ♿ **Accessible** - ARIA labels, semantic HTML, keyboard navigation
- ⚡ **Zero Dependencies** - Pure HTML, CSS, and vanilla JavaScript
- 🎨 **Modern UI** - Clean design with smooth animations
- 🧪 **Automated Testing** - Headless Chrome verification script

## 📦 Installation & Setup

### Quick Start

1. **Clone the repository**
```bash
git clone https://github.com/kartik-33s/CodeHUB-chatbot.git
cd CodeHUB-chatbot/india-is-one-of-the-world
```

2. **Open in browser**
```bash
# Simply open the HTML file
# Windows
start outputs/index.html

# Mac
open outputs/index.html

# Linux
xdg-open outputs/index.html
```

That's it! No build process needed.

### Development Setup

For testing and verification:

```bash
# Install Node.js (if not already installed)
# Then run the verification script
cd work
node verify-dashboard.js
```

## 🎮 How to Use

### 1. Explore Overview
- View headline metrics (best rank, areas needing attention)
- Check the Progress Compass radar chart
- Generate AI insights with different lenses

### 2. Search & Filter
- Use the search box to find specific indicators
- Filter by category (Economy, Technology, Environment, etc.)
- Sort by best rank, needs attention, or latest year

### 3. Compare Countries
- Select an indicator to compare
- Choose peer group (Global anchors, South Asia, Large emerging)
- View historical trends

### 4. Ask Questions
- Type natural language queries like:
  - "Show India's innovation ranking"
  - "What is GDP rank?"
  - "Tell me about environment"

### 5. Export Data
- Click **"Export CSV"** to download all data
- Click **"Annual report card"** for comprehensive text report
