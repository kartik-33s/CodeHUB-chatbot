# Demo Guide - India in the World Dashboard

**🎥 For Video Demo Recording - 3 to 5 Minutes**

This guide will help you create an effective demo video for the Lets Code Development Challenge 2026.

---

## 📹 Demo Script

### Introduction (30 seconds)

> "Hi, I'm presenting **India in the World** - a comprehensive dashboard that answers the question: Where does India stand on the global stage?
>
> Instead of searching through hundreds of reports from the UN, World Bank, IMF, and other organizations, this platform consolidates global rankings into a single, interactive experience."

**Action**: Show the homepage with the main heading and hero section.

---

### Part 1: Dashboard Overview (1 minute)

> "The dashboard tracks 13 global indicators across economy, technology, governance, environment, and quality of life."

**Show**:
1. **Headline Metrics** (top of page)
   - "We can see 13 indicators are loaded"
   - "India's strongest rank is #6 in GDP"
   - "4 areas need attention"

2. **Progress Compass** (radar chart)
   - "This radar chart converts ranks into percentiles"
   - "Higher is better across all categories"
   - "We can see India performs well in Economy and Technology"
   - "But needs improvement in Environment and Press Freedom"

3. **Top Rankings Strip**
   - "These are India's top 4 strongest indicators"

---

### Part 2: AI-Powered Insights (45 seconds)

> "The platform includes AI-powered analysis capabilities."

**Demonstrate**:
1. **Analysis Lens**
   - Click dropdown, show options: "Balanced, Economy, People, Governance, Environment"
   - Select "Economy"
   - Click "Generate insight"
   - Read the generated insight aloud

2. **Natural Language Query**
   - Type: "Show India's innovation ranking"
   - Click "Ask" or press Enter
   - Show how it scrolles to the indicator and displays info

**Example**: "What is GDP rank?" or "Tell me about environment"

---

### Part 3: Explore Indicators (1 minute)

> "Let's explore the indicator cards. Each card shows comprehensive information."

**Show**:
1. **Search & Filter**
   - Type "innovation" in search box
   - Show filtered results
   - Clear and select category "Technology"
   - Show rank band filter (top/middle/bottom third)
   - Change sort to "Needs attention"

2. **Indicator Card Details**
   - Click on an indicator card (e.g., "Global Innovation Index")
   - Show the drawer that opens with:
     - Full description
     - Why it matters
     - Recent movement
     - Percentile calculation
     - Source link

---

### Part 4: Compare & Trends (1 minute)

> "We can compare India with other countries and see historical trends."

**Demonstrate**:
1. Scroll to **Compare Countries** section
2. Select indicator: "Human Development Index"
3. Change peer group: "South Asia"
4. Show the comparison bar chart
5. Read the comparison note: "India trails X countries..."

6. Show **Trend Line** dropdown
7. Select "Global Innovation Index"
8. Point out: "India improved from rank 48 in 2020 to 38 in 2025"

---

### Part 5: Interactive Map (30 seconds)

> "The interactive world map lets you explore rankings geographically."

**Show**:
1. Select map indicator dropdown
2. Choose different indicator
3. Click on country pins to see their ranks
4. Show comparison with India

---

### Part 6: Catalog & Export (45 seconds)

> "The platform is designed for the full challenge requirements."

**Show**:
1. **Required Indicator Catalog**
   - Click through category tabs (Economy, Technology, Education, etc.)
   - Show green items (live in dashboard)
   - Show gray items (planned coverage)
   - "13 indicators are live, with 50+ more planned"

2. **Challenge Readiness**
   - Scroll through readiness grid
   - Point out: "All judging criteria are addressed"

3. **Export Features**
   - Click "Export CSV" → Show download
   - Click "Annual report card" → Show download
   - "Both downloads provide comprehensive data export"

4. **Source Ledger**
   - Scroll to sources table
   - "Every metric links to its original source for transparency"

---

### Conclusion (30 seconds)

> "Let me quickly show the responsive design."

**Action**: 
- Resize browser to mobile width
- Scroll through the mobile view
- Show that all features work

**Closing**:
> "India in the World consolidates scattered global data into an accessible, transparent platform with:
> - 13 indicators with verified sources
> - AI-powered insights and natural language queries
> - Country comparisons and historical trends
> - Interactive visualizations and responsive design
> - Complete data export capabilities
>
> Thank you for watching. The source code is available on GitHub."

## 🎬 Recording Tips

### Technical Setup
- **Resolution**: 1920x1080 (Full HD)
- **Browser**: Chrome or Firefox (latest version)
- **Screen Recording**: OBS Studio, Loom, or QuickTime
- **Audio**: Use a good microphone, test levels first
- **Zoom**: Keep text readable (125% zoom if needed)

### Presentation Tips
1. **Speak clearly and enthusiastically**
2. **Pace yourself** - Don't rush through features
3. **Show, don't just tell** - Click buttons, type queries
4. **Keep cursor movements smooth** - No erratic movements
5. **Add smooth transitions** - Use fade or cut between sections
6. **Highlight important elements** - Use cursor or annotations

### Video Editing
- **Intro slide** (5 seconds): Project name + your name
- **Background music** (optional): Low volume, non-distracting
- **Captions** (recommended): Add text overlays for key features
- **Outro slide** (5 seconds): GitHub link + Thank you

### Common Mistakes to Avoid
❌ Too much dead air/silence  
❌ Mouse cursor jumping around  
❌ Unclear audio or background noise  
❌ Going over 5 minutes  
❌ Not showing actual interactions  
❌ Forgetting to mention data sources
